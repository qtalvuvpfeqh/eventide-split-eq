## Overview

Eventide Split EQ separates audio into transient and tonal streams and applies independent EQ adjustments to each, enabling precise tone shaping impossible with conventional EQ alone.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Eventide Split EQ** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Transient EQ** | Apply EQ boosts and cuts to only the transient component of audio |
| **Tonal EQ** | Shape only the tonal, sustained component independently |
| **Visual Analyzer** | Real-time spectrum shows both transient and tonal components |
| **Mid/Side** | Full mid/side mode for mastering and stereo stem processing |
